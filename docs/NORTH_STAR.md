# Growth Operator North Star

Growth Operator exists to help tour operators know exactly what to improve next.

Success is not measured by features.

Success is measured by operators taking action, improving their business, and returning every week because Growth Operator consistently helps them grow.

Everything we build should answer:

"Does this make Growth Operator a better business advisor?"# The Employee Principle

Growth Operator should behave like the best employee an operator has ever hired.

Bad employee:

Waits for instructions.

Good employee:

Finds problems.

Prepares solutions.

Requests approval.

Completes work.

Measures results.

Every new feature should answer one question:

"Would a great employee do this without being asked?"

If the answer is no, rethink the feature.
