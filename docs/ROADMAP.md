# Guiding Principle

Growth Operator is not a marketing agency.

Growth Operator is an operating system that helps tour operators know exactly what to improve next.# Product Systems on the Horizon

## Build 026 — Universal Public Scan

Immediate priority.

Begin allowing GO to understand operators it has never analyzed before using publicly available website and business information.

Future public intelligence layers may include:

- Website crawling and business understanding
- Products and pricing
- Booking flow and provider detection
- Reviews and reputation
- Competitors
- Search visibility
- Search demand
- Organic traffic opportunity
- Public traffic estimates when useful

Paid third-party data providers should be considered accelerators, not requirements.

Prefer public evidence and GO-owned analysis when reliable.

---

## GO Review Engine

Reviews should become a first-class GO growth system.

Future capabilities should include:

- Review baseline and Review Score
- Review velocity
- Competitor review benchmarking
- Automated post-experience review campaigns
- Intelligent SMS / email / messaging timing
- Tour and experience-specific messaging
- Review conversion measurement
- Review response assistance
- Review sentiment and theme analysis
- Identification of customer-loved differentiators
- Connecting reputation improvement to visibility, conversion, bookings, and revenue where evidence supports it

GO should not simply send review requests.

GO should continuously improve how effectively happy customers become public advocates.

---

## GO Website Engine

GO should eventually be capable of generating and operating an optimized website based on intelligence gathered about the business.

The website should not begin from a generic AI prompt.

It should begin from GO's understanding of:

- The business
- Experiences
- Customers
- Reviews
- Search demand
- Competitors
- Conversion problems
- Booking behavior
- Brand positioning

GO should be capable of recommending, building, hosting, managing, testing, and continuously improving the website.

Website ownership should never become artificial customer imprisonment.

Domains, business data, brand assets, analytics, and customer data belong to the operator.

GO Website customers should have clear transfer/buyout terms if they leave.

The website should create retention because GO continuously improves it — not because the operator is held hostage.

---

## Mobile GO

Desktop = command center.

Mobile = daily relationship with GO.

Notifications = GO proactively comes to the operator.

Mobile should emphasize:

- What GO accomplished
- What changed
- Measured impact
- What GO is currently working on
- The small number of things requiring operator approval

Mobile GO should reduce work, not become another inbox.
